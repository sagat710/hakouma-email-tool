# ハコウマスタジオ メール作成支援ツール

テンプレートを選んで項目を入力すると、返信メールをリアルタイムでプレビューし、
ワンクリックでコピーできる静的Webツールです。
（susumuharada.com の Mebic メール作成支援ツールと同じ使用感）

## 使い方

1. 左の **テンプレート一覧** から返信の種類を選ぶ
   - ①入金案内（銀行振込）
   - ②入金案内（クレジット・PayPal）
   - ③ご予約確定のお知らせ
2. 中央の **内容編集** で各項目を入力する（宛名・拠点・予約内容・ご利用料金 など）
3. 右の **プレビュー** で件名・本文を確認する
4. **「クリップボードにコピー」** ボタンでコピーして、メールに貼り付ける

入力した内容はリアルタイムでプレビューに反映されます。

### メール本文から自動入力（任意）

「内容編集」右上の **「メール本文から自動入力」** ボタンを押すと、予約メールの
本文を貼り付けて項目を自動入力できます。

- 支払い方法（銀行振込／クレジットカード・PayPal）から**テンプレートを自動選択**
- **宛名**（会社・団体名＋氏名）・**予約内容**（◎ご利用プラン）・**ご利用料金** を自動抽出
- 抽出できなかった項目（PayPalのURL など）はメッセージで案内されるので、手入力してください
- **拠点（大阪／東京）は自動判定できないため、自動入力後に手動で選択してください**

### 拠点（大阪／東京）の切り替え

各テンプレートに「拠点」のプルダウンがあり、大阪／東京を選ぶと以下がその場で自動的に
切り替わります（お問い合わせ電話番号・振込先口座は共通のため変わりません）。

- 到着案内の一文（お越しいただく場所）
- ■■アクセス■■（住所・道順）
- ビルへの入館案内
- ご利用前の注意事項
- お問い合わせ先（メールアドレス）

## 起動方法（ローカル確認）

`fetch()` でテンプレートを読み込むため、ファイルを直接開くのではなく
簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## デプロイ

静的ファイル（`index.html` / `style.css` / `app.js` / `data/`）をそのまま
静的ホスティングにアップロードするだけで動作します。

- Render を使う場合は `render.yaml`（Static Site 設定）を利用できます。
- アクセス制限が必要な場合は、Mebic ツールと同様に **ホスティング側の
  Basic認証**（`.htaccess` 等）で保護してください。

## テンプレートの編集・追加

テンプレートは `data/templates/` 内の Markdown ファイルです。
新規追加したら `data/template_list.json` にファイル名を追加してください。

### フロントマター

```
---
name: 一覧に表示される名前
subject: 件名（{項目} を含められます）
---
本文（{項目} を含められます）
```

### プレースホルダー（入力欄）の書き方

本文・件名に `{...}` を書くと、その分だけ入力欄が自動生成されます。

| 書き方 | 生成される入力欄 | 例 |
| --- | --- | --- |
| `{項目名}` | 1行テキスト | `{ご利用料金}` |
| `{text:項目名}` | 複数行テキスト | `{text:予約内容}` |
| `{date:項目名}` | 日時（自動で和暦表記に整形） | `{date:利用日時}` |
| `{time:項目名}` | 時刻 | `{time:開始時刻}` |
| `{項目名:初期値}` | 1行テキスト（初期値あり） | `{担当者名:原田}` |
| `{項目名:+7d}` | 「今日から7日後（M月D日）」を初期値に | `{お振込期日:+7d}` |
| `{select:項目名:選択肢1,選択肢2}` | プルダウン選択 | `{select:拠点:大阪,東京}` |

同じ項目名は自動で1つの入力欄にまとめられ、本文中の全ての箇所に反映されます。

### 拠点（大阪／東京）で自動計算される項目

`{select:拠点:大阪,東京}` と組み合わせて、以下の項目は **入力欄を作らず**、
選択された拠点に応じて `app.js` 内の `LOCATIONS` の内容へ自動置換されます
（拠点ごとの住所・電話番号・注意事項などを増やしたい場合は `LOCATIONS` を編集してください）。

- `{拠点到着案内}` … 到着案内の一文
- `{拠点住所}` … アクセス（住所・道順）
- `{拠点入館案内}` … ビルへの入館案内
- `{拠点注意事項}` … ご利用前の注意事項
- `{拠点問い合わせ}` … お問い合わせ先（メール・電話）
